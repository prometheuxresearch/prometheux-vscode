# Run a concept

Press **Cmd/Ctrl+Shift+Enter** (or the ▶ button in the editor title) in a concept to run it on
the platform. Live status goes to the **Prometheux** output channel, and the results open in the
**Prometheux → Results** panel, page by page.

In a local `.vada` file the same shortcut evaluates the whole program without saving anything.
